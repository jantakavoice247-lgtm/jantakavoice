Security & Risks

🛡️ V1 Security (built-in)

  • ✅ JWT + refresh tokens
  • ✅ Password hashing (bcrypt)
  • ✅ Role-based access
  • ✅ Input validation (Zod)
  • ✅ Rate limiting
  • ✅ HTTPS + security headers
  • ✅ File validation (type + size)

🔴 Critical Risks (monitored)

  • 🔴 Contributor identity leak
  • 🔴 Admin account compromise
  • 🔴 Fake news amplification
  • 🔴 Database breach
  • 🔴 AI-generated misinformation
⚠️ Aadhaar, auto-fact-check, deepfakes → V2/V3
